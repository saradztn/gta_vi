# Royal Citadel — مشروع مستقل لـ MTA:SA 1.6+

هذا مجلد مشروع مستقل جديد باسم `royal_citadel_mta/`. لم يتم تعديل `source.zip` أو استخراج ملفاته إلى هذا المشروع أو دمجها معه. أُعيد تنفيذ أدوات البناء هنا بصورة مستقلة وباعتماد Python القياسي فقط.

## ما الذي ينتجه المشروع؟

- **21 نوعًا من الأصول المعيارية**: جزيرة/هضبة صخرية، قصر مركزي، أجنحة ملكية، أسوار وأبراج دائرية ومدببة، بوابات مقوسة، جسر صاعد، درج احتفالي، أجنحة حدائق، نوافير، تماثيل، أشجار صنوبر، تحوطات، أعلام، مصابيح، شلالات، وخندق مائي.
- **205 مواضع** تُركّب هذه الوحدات في قلعة ومدينة ملكية على هضبة جبلية. القصر المركزي هو العنصر الأعلى والأكبر.
- **42 ملف DFF**: نسخة تفصيلية ونسخة LOD منخفضة لكل نوع من الأنواع الـ21.
- **17 ملف COL3**: تصادم شبكي للهضبة والجسر والتلال، وصناديق تصادم أبسط للوحدات المعمارية. العناصر الزخرفية غير القابلة للمشي لا تحمل تصادمًا.
- **TXD مشترك** يضم تسع خامات DXT1 مع سلسلة mipmaps كاملة.
- مورد MTA كامل في `resource/RoyalCitadel/`، مع `meta.xml` وسكربتات العميل والخادم وملفات النماذج والتخطيط.

## الخامات والصور

توجد صور المصدر الأصلية تحت `assets/albedo/`. هذه صور خامات **مولّدة فعليًا بالذكاء الاصطناعي**، وليست خرائط ضوضاء أو صورًا مرسومة ببكسلات عبر Python:

| صورة المصدر | الاستخدام |
|---|---|
| `limestone_fresh.png` | حجر جيري جديد |
| `limestone_aged_moss.png` | حجر قديم متآكل وطحلب |
| `slate_roof.png` | ألواح أسقف أردوازية داكنة |
| `ivory_marble.png` | رخام عاجي |
| `aged_copper.png` | نحاس معتّق |
| `gilded_bronze.png` | برونز مذهّب |
| `oak_wood.png` | خشب بلوط |
| `courtyard_cobble.png` | رصف ساحات |
| `cliff_gneiss.png` | صخور جرف جبلية |

صور المصدر 1024×1024؛ يحوّلها البناء إلى 512×512، ويضغطها إلى DXT1 مع mipmaps داخل TXD. لا ينشئ خط البناء خامات ضوضاء بديلة. الماء والنباتات والأعلام والزجاج المضيء ممثلة في هذه النسخة بهندسة وألوان مواد داخل DFF بدل خرائط صور منفصلة.

## البناء والتحقق

يتطلب البناء Python 3.10 أو أحدث، ولا يحتاج إلى NumPy أو Pillow أو SciPy:

```bash
cd royal_citadel_mta
python3 build.py
python3 validate_build.py
```

يكتب البناء مخرجاته داخل `resource/RoyalCitadel/` فقط، ولا يمسح ملفات غير تابعة له. فاحص البناء يتحقق من بنية DFF/TXD/COL3، وفهارس المثلثات ومواد DFF، ومطابقة الخامات، ومحتويات `meta.xml` ووجود ملفات LOD.

## التثبيت في MTA

1. انسخ المجلد `resource/RoyalCitadel/` إلى مجلد `resources/` في خادم MTA.
2. شغّل المورد: `start RoyalCitadel`.
3. استخدم `/royalcastle` للانتقال إلى الموقع، و`/royalexit` للعودة إلى موقعك السابق.
4. أوامر العميل: `/royalshow` و`/royalhide` و`/royalinfo`.

تُحمّل النماذج بأرقام نماذج مخصصة عبر دعم MTA 1.6+، وتُنشأ المشاهدات محليًا لكل عميل كي لا تستبدل مباني GTA الأصلية. إحداثيات مركز الموقع الافتراضية هي `(2500, 2500, 0)`؛ إذا غيّرتها، حدّثها في `build.py` و`resource/RoyalCitadel/server.lua` معًا.

## ملاحظات الجودة والتشغيل

- البيئة مُركّبة من وحدات صغيرة مع LOD فعلي مقترن بـ`setLowLODElement`، وليست DFF ضخمًا واحدًا.
- نسخ MTA:SA 1.6+ مبنية على RenderWare/D3D9؛ لذلك المخرجات متوافقة مع قيود ذلك المحرك وليست نظام PBR/normal-map حديثًا. كلمة «AAA» هنا وصف للاتجاه الفني، وليست ادعاءً بأن محرك San Andreas يعادل محركات الألعاب الحديثة.
- الاختبار المنفّذ هو فحص بنيوي مستقل **(100 تحقق ناجح)**. لا تتوفر بيئة تشغيل MTA أو عميل لعبة هنا، لذلك لم أستطع تأكيد ظهور الأصول فعليًا داخل عميل اللعبة.
- أُنتجت تسع صور خامات AI في هذه الجولة؛ وصل توليد الصور إلى حدّه لهذه الجولة، لذلك لم أضف صور AI مستقلة للماء أو الأعشاب أو راية القصر. يمكن استبدال/إضافة تلك الصور لاحقًا ثم إعادة بناء TXD.
